# WeldVision 시연 사용 가이드

## 1. 시연 전 확인

다음 두 모델 파일이 로컬에 있어야 한다.

```text
runs/detect/rt-v4-balanced/weights/best.pt
runs/detect/vt-v1-balanced/weights/best.pt
```

모델 가중치는 Git 저장소에 포함되지 않는다. 다른 PC에서 실행할 때는 가중치를 별도로 옮기고 앱의 모델 경로를 확인한다.

## 2. 앱 실행

```powershell
python phase2/gradio_app.py
```

브라우저에서 `http://127.0.0.1:7860/`을 연다.

## 3. 검사 방식 선택

| 원본 폴더 | 선택할 검사 방식 | 주요 클래스 |
|---|---|---|
| `TS_RTAL_*`, `TS_RTST_*` | 방사선 검사(RT) | 균열, 기공, 융합불량, 슬래그혼입 |
| `TS_VTST_*` | 육안 검사(VT) | 기공, 용입부족, 융합불량, 언더컷 |

| VT 파일명 예 | 결함 |
|---|---|
| `VT_ST_02_*` | 기공 |
| `VT_ST_03_*` | 용입부족 |
| `VT_ST_04_*` | 융합불량 |
| `VT_ST_06_*` | 언더컷 |
| `VT_ST_00_*` | 정상 |

RT 사진을 VT 모델로 분석하거나 VT 사진을 RT 모델로 분석하면 결과는 무효다.

## 4. 기본 사용 순서

1. `검사 방식`에서 RT 또는 VT를 선택한다.
2. 용접 이미지를 업로드한다.
3. 모델 경로가 선택한 검사 방식의 `best.pt`로 바뀌었는지 확인한다.
4. `분석 시작`을 누른다.
5. 원본과 검출 결과의 박스 위치를 비교한다.
6. 결함명과 신뢰도를 확인한다.
7. 전처리 근거 화면과 분석 결과 요약을 함께 본다.

기본 YOLO 신뢰도는 RT 0.10, VT 0.25다. 낮은 신뢰도 박스까지 확인할 때만 `낮은 신뢰도 검토 후보도 표시`를 켠다.

## 5. 결과 읽는 법

- **굵은 박스**: 현재 신뢰도 기준을 통과한 주요 검출이다.
- **얇은 review 박스**: 기준보다 낮지만 모델이 후보로 본 영역이다. 확정 결함이 아니다.
- **Confidence**: 해당 종류에 대한 모델 신뢰도다. 결함의 심각도나 합격 확률이 아니다.
- **Risk**: 프로젝트의 설명용 규칙으로 계산한 위험도다. 산업 표준 판정값은 아니다.
- **전처리 화면**: 사람이 결함의 대비·경계·질감을 확인하는 보조 자료다.

박스가 결함 전체보다 좁거나 여러 조각으로 나뉠 수 있다. 종류가 맞더라도 위치 품질은 원본 JSON 또는 육안과 따로 비교한다.

## 6. 슬라이더 사용법

| 조절값 | 역할 |
|---|---|
| YOLO 신뢰도 | 표시할 모델 검출의 최소 신뢰도 |
| CLAHE 강도 | 흐린 영역의 국소 대비 강화 |
| Black-hat 크기 | 어두운 결함과 비교할 주변 영역 크기 |
| 어두운 후보 임계값 | OpenCV 후보의 어두운 정도 기준 |
| 최소 후보 면적 | 너무 작은 노이즈 후보 제거 |
| Gradient 부드러움 | 경계 화면의 노이즈와 세부 정도 조절 |
| Emboss 깊이 | 표면 질감 강조 정도 |
| 샤프닝 강도 | 화면 선명도 조절 |

이 값들은 YOLO를 재학습시키지 않는다. Black-hat 크기는 모델 정확도를 올리는 버튼이 아니라 전처리 화면에서 강조할 어두운 패턴의 크기를 정하는 값이다.

## 7. 결과가 이상할 때

1. RT/VT 선택이 맞는지 확인한다.
2. 파일명 또는 원본 폴더의 결함 종류를 확인한다.
3. 같은 이름의 JSON이 있으면 정답 폴리곤과 비교한다.
4. 신뢰도를 0.05씩 조절한다.
5. 낮은 신뢰도 후보는 결함으로 단정하지 않는다.
6. 정상 이미지에 박스가 나오면 오검출 사례로 기록한다.

결과를 억지로 맞추기보다 성공·실패 사례를 각각 저장해 모델의 한계로 설명하는 편이 올바르다.

## 8. 권장 시연 순서

1. VT 용입부족 예시로 정확한 클래스 검출을 보여준다.
2. VT 언더컷 예시로 여러 개의 작은 결함 박스를 보여준다.
3. RT 예시로 검사 방식에 따라 모델이 자동 전환되는 것을 보여준다.
4. 전처리 화면과 위험도·권장 조치를 설명한다.
5. “검사 보조 프로토타입이며 최종 판정은 원본과 함께 수행한다”고 안내한다.

상세 성능과 한계는 [최종 프로젝트 보고서](final-project-report.md)에 정리되어 있다.
