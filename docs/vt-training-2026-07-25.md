# VT YOLOv8s 학습 결과 (2026-07-25)

## 목적

RT 방사선 이미지와 외관이 다른 VT 육안 검사 이미지를 별도 모델로 학습했다. `incomplete_penetration`(용입부족)을 포함한 VT 4개 결함을 검출하고, Gradio 앱에서 RT/VT 검사 방식에 따라 알맞은 모델을 사용하도록 연결하는 것이 목표다.

## 데이터 구성

원본 VT 데이터는 학습 59,212장, 검증 7,398장이었다. 첫 VT 모델은 클래스 폴더별 최대 3,000장을 변환한 뒤, 기공과 정상 이미지의 비중을 줄인 균형 학습 목록을 사용했다.

| 구분 | 이미지 | 비고 |
|---|---:|---|
| Train | 11,456 | 균형 목록 적용, 정상 2,000장 포함 |
| Validation | 6,805 | 정상 3,000장 포함 |

학습 목록의 결함 박스는 기공 10,009개, 융합불량 4,265개, 용입부족 4,051개, 언더컷 6,693개다. 면적이 0인 잘못된 박스와 VT 범위 밖 클래스가 섞인 이미지는 변환 과정에서 제외했다.

## 앱 확인

`VT_ST_03_14601260.jpg`를 VT 모드와 기본 신뢰도 0.25로 분석했을 때 `incomplete_penetration`을 신뢰도 0.755로 검출했다. 주 박스는 원본 JSON의 용입부족 영역과 거의 일치했고, 낮은 신뢰도의 가장자리 후보는 기본 임계값에서 제거됐다.

앱에는 RT/VT 선택 기능을 추가했다. RT는 기본 신뢰도 0.10, VT는 0.25를 사용하며 선택한 검사 방식에 맞는 `best.pt` 경로를 자동 적용한다.
